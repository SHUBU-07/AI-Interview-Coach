# AI Interview Coach: Study Results

**Status: pending data collection.**

This file is generated by `python run_pipeline.py` from the real study data and is overwritten each run.
It intentionally contains no numbers until the study has been run.

To produce it:

1. Collect answers and blind human ratings in the app (see README, "Running the study").
2. Run `python run_pipeline.py --rescore`.

To check that the pipeline works before you have data, run `python run_pipeline.py --demo`.
That writes `results_demo.md` from synthetic data and a mock model. Never cite demo numbers.
